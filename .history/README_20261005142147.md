# HW2 — Tidy, Join, and Analysis-Ready Data

## Repository layout
```
data/raw/           raw data, untouched (3 source CSVs)
notebooks/analysis.ipynb   all six tasks, runs top to bottom
output/              charts + final analysis-ready CSVs (generated by the notebook)
WRITEUP.md           written answers to every question, in order
```

## Setup
```
pip install -r requirements.txt
```

## Run
```
jupyter nbconvert --to notebook --execute notebooks/analysis.ipynb
```
